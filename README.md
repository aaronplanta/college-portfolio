# My College Portfolio

This is my personal college portfolio, created to showcase my work and document my learning throughout college. It serves as a place to share my projects, skills, and growth as a student.

The portfolio is built with React.

## Run locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

## Build

Create a production build:

```bash
npm run build
```
